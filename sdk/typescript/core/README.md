# @laya-js/core

Isomorphic types, question builders, answer readers and context budgeting for the Laya decision model. Zero dependencies, runs in the browser and in Node.

Laya cannot run in a browser: ~1.7 GB of weights on ONNX Runtime under Node.
See the [monorepo README](../../README.md) for the architecture, quick start, API and
security notes.
